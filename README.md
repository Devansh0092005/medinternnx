# MedInternX — ₹0 Website

This is a static, no-Node.js starter for MedInternX.

## Free publishing with GitHub Pages
1. Create a free GitHub account.
2. Create a public repository named `medinternx`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch → main → / (root)**.
6. Your site will get a free `github.io` address.

## Included
- Modern MedInternX homepage
- 6 free internship tracks
- Internship detail popups
- Student dashboard UI
- Registration/login UI
- Mobile responsive layout
- Certificate fee is not shown before completion

## Important
This package is the free static frontend. The forms are demo-only until a real authentication/database backend is connected. A free-tier backend such as Supabase can be added later for real accounts, saved progress and completion records. Free service limits can change.

No Node.js, Netlify, Lovable or paid hosting is required for the static website.
