## Update the live GitHub Pages site

1. Run `supabase_content_update.sql` in Supabase SQL Editor.
2. In GitHub repository `Devansh0092005/medinternnx`, upload/replace these files in the repository root:
   - `index.html`
   - `style.css`
   - `script.js`
   - `course_content.js`
   - `supabase_content_update.sql`
3. Commit the changes.
4. Wait for GitHub Pages to deploy.

Keep your existing `config.js` unchanged so the Supabase connection remains configured.

The content is educational and beginner-friendly. Real clinical, regulatory, pharmacovigilance and AI work should follow current official guidance, applicable law and organizational procedures.
